# E-Commerce Search Engine Project

## Overview

This repository contains the work for a university project focused on the design, implementation, and evaluation of search engines for e-commerce.

Acting as a consulting team for an online retail company, we investigate common causes of poor search performance, develop improved search solutions, and evaluate their effectiveness using product data, search queries, relevance judgments, and log data.

The project follows the complete Information Retrieval (IR) workflow, including indexing, retrieval, ranking, evaluation, documentation, and presentation of results.

---

## Project Objectives

The main objectives of this project are:

- Investigate common reasons for poor search performance in e-commerce product search.
- Design and implement improved search engine configurations.
- Evaluate search quality using established Information Retrieval metrics.
- Compare different retrieval and ranking approaches.
- Present findings and recommendations in a clear and actionable manner.

---

## Project Assignments

### Assignment 1 – Search Engine Setup & Indexing

- Set up a search engine environment.
- Index the provided TREC Product Collection.
- Document indexing strategies and configurations.

### Assignment 2 – Project Planning & Documentation

- Define project scope and objectives.
- Document system architecture and design decisions.
- Maintain project documentation and lab notes.

### Assignment 3 – Search Engine Development

- Implement and compare different search approaches.
- Experiment with ranking methods and retrieval models.
- Analyze potential improvements for product search.

### Assignment 4 – Evaluation

- Evaluate search quality using relevance judgments and query logs.
- Calculate retrieval effectiveness metrics.
- Compare the performance of different search configurations.

### Assignment 5 – Final Presentation

- Summarize methodology and findings.
- Present evaluation results.
- Provide recommendations for improving the e-commerce search experience.
