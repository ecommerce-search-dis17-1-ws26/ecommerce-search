# Project Plan

## Objectives
- Diagnose weak relevance in product search.
- Implement and compare multiple retrieval strategies.
- Evaluate improvements using standard IR metrics and query logs.

## Scope
- Product indexing pipeline from TREC-style product collection.
- Multiple ranking modes (keyword baseline, BM25, BM25 with query expansion).
- Evaluation pipeline with Precision@K, Recall@K, MAP, and NDCG.

## Milestones
1. Setup and indexing.
2. Documentation and architecture.
3. Retrieval engine implementation and comparison.
4. Evaluation and analysis.
5. Presentation and recommendations.
